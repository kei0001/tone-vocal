# tone — 音程トレーナー

ブラウザのマイクで10秒間のロングトーンを練習できるプロトタイプです。

## 機能

- C3〜C5のお手本音を再生
- 声の音程と目標との差をリアルタイム表示
- ±25 cents以内の一致率と最長連続キープ時間を計測
- 結果に応じたルールベースの練習アドバイス

音声はWeb Audio APIとYIN方式の音高推定で端末内処理します。音声の録音・保存・送信や、学習型AIモデルの利用はありません。

## ローカルで動かす

ビルドや依存パッケージのインストールは不要です。Python 3がある環境で実行します。

```sh
python3 -m http.server 8000 --directory dist
```

ブラウザで http://localhost:8000 を開き、マイクを許可してください。別の端末からアクセスする場合はHTTPS配信が必要です。

## ファイル構成

- `dist/index.html`: 画面
- `dist/style.css`: レスポンシブスタイル
- `dist/app.js`: マイク入力、描画、練習と採点
- `dist/pitch.js`: 単音の音高推定

## 検証状況・制限

44.1kHz / 48kHzの合成音28ケースと無音で音高推定を確認済みです。実際の歌声やiPhone実機での動作・精度は未検証です。伴奏のない単音を想定しており、雑音・倍音・マイク特性により誤検出する場合があります。発声方法や健康状態を診断するものではありません。
